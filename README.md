# SurfNIRS: Surf Your fNIRS Data with Ease!
Hello SurfIR! Welcome to SurfNIRS, an **all-in-one data surfer for fNIRS data**.

## Compatability
Currently supports:
1. AnalyzIR (NIRS Toolbox)
2. Homer3
3. Homer2
4. Raw .nirs
